# Multi-Class Dental Disease Image Dataset for AI-Based Classification
A cleaned multi-class dental disease image dataset for AI-based classification and research.

## Overview

This repository provides documentation and resources for the Multi-Class Dental Disease Image Dataset, developed for AI-based dental image classification and research.

The dataset contains dental images organized into nine classes, covering different dental conditions, healthy teeth, and non-dental images. It is intended to support researchers, students, and developers working on computer vision and AI-assisted dental applications.

## Dataset Classes

The dataset contains the following nine categories:

- Calculus
- Caries
- Cavities
- Gingivitis
- Healthy
- Hypodentia
- Malocclusion
- Non-Teeth
- Tooth Discoloration

## Dataset Access

The complete dataset can be accessed through the following platforms:

- **Zenodo:** (https://zenodo.org/records/24478747)
- **Kaggle:** (https://doi.org/10.34740/kaggle/dsv/22724040)

## Dataset Preparation

The dataset underwent cleaning and duplicate-image checking to improve its organization and quality.

The preparation process included:

- Dataset organization into class-wise folders.
- Duplicate image detection.
- Removal of identified duplicate images during dataset cleaning.
- Organization of images into nine categories.

## Intended Uses

This dataset may be used for:

- Dental image classification research.
- Machine learning and deep learning experiments.
- Computer vision applications.
- AI-assisted dental screening research.
- Educational and academic projects.

## Limitations

This dataset is intended for research and educational purposes. Models trained using this dataset should not be considered a replacement for professional dental examination, clinical diagnosis, or advice from qualified dental professionals.
